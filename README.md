# Unity NavMesh & Netcode Learning Project

## 🎮 Project Overview

This is a Unity-based game project developed for **learning, experimentation, and coursework purposes**, not for commercial use.

The main objectives of this project are:
- Learning and experimenting with **NavMeshAgent** for AI movement, pathfinding, obstacle avoidance, and target chasing
- Exploring **Unity Netcode (Netcode for GameObjects)** to understand multiplayer fundamentals such as state synchronization, authority, and RPCs
- Practicing **game system design**, clean code structure, and Unity development workflows

This project focuses on **understanding core systems rather than polish**. Some mechanics or implementations may be incomplete or unoptimized, as the goal is to learn through experimentation.
